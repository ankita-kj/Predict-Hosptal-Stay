## Komme i Gang
Følg disse trinnene for å kjøre prosjektet

## 1. Datatilberedning
Først må du kjøre datatilbredning.ipynb for å forberede datasettene. 

## 2. Visualisering
Etter datatilberedningen, kjør Visualisering.ipynb for å se den utforskende dataanalysen. 

## 3. Modellering
Kjør Modellering.ipynb for å evaluere ulike maskinlæringsmodeller på de forberedte dataene. Dette trinnet kan ta litt tid, da alle modellene skal evalueres. 

Alt kan kjøres i Jupyter Notebook. Du kan enkelt kjøre alle filene ved å klikke på "Run All Cells". 

## Nettside 
Kjør app.py for å laste inn nettsiden. Gå deretter inn på din foretrukket nettleser og skriv inn http://localhost:8080/. Alle feltene på nettsiden krever input for å gi en predikasjon.
